# Aoex Shimeji Archive Repository 
Personal collection of Shimeji (desktop mascots) of characters the series Blue Exorcist. These are archived solely for preservation purposes as most creators that created them are lost to time.

These have all been updated & transferred to a forked 2022 version of [Shimeji-ee from kilkakon](https://kilkakon.com/Shimeji/) to retain functionality from the deprecated 2009 Shimeji version.

I'd like for these cute little guys to live on...

# Installing
Each folder contains their own version of <code>Shimeji-ee.jar</code> (including it's <code>README.txt</code> and <code>LICENSE.txt</code> files for preservation).

Simply install the folder of your desired character and then open the <code>Shimeji-ee.jar</code> file.

# Updating
All of the Shimeji's can be updated by simply replacing the newer version of <code>Shimeji-ee.jar</code>, <code>lib</code> and <code>conf</code> folder. Do not replace the <code>img</code> folder.

**EXCEPTION:** The Coal Tar Shimeji has different configurations, it needs to retain the code from <code>actions.xml</code> and <code>behaviors.xml</code> that dictates the number of images it actually has.
