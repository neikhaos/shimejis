# Aoex Shimeji Archive Repository
![preview](https://github.com/neikhaos/shimejis/blob/main/preview.png)
Personal collection of Shimeji (desktop mascots) of characters from the series Blue Exorcist. These are archived solely for preservation purposes as most are lost to time.

These have all been updated & transferred to a forked 2022 version of [Shimeji-ee from kilkakon](https://kilkakon.com/Shimeji/) to retain functionality from the deprecated 2009 Shimeji version.

I'd like for these cute little guys to live on...

# Installing
- Note: Each folder contains their own version of Shimeji-ee so they can be used straight out of the box.
    - This means they all include the files: <code>Shimeji-ee.jar</code>, <code>README.txt</code>, <code>LISCENSE.txt</code>, and the folders: <code>conf</code> & <code>lib</code>.

## Guide
1. Install the latest version of [Java](https://www.java.com/en/download/)
2. Simply download the folder of your desired character and then open the <code>Shimeji-ee.jar</code> file to run the desktop mascot.
   - You can configure the Shimeji by right clicking on the character, or the desktop icon.
3. If you encounter any issues, follow the [Shimeji-ee guide included in the README.txt file](https://github.com/neikhaos/shimejis/blob/main/Characters/Amaimon/README.txt)

# Updating
Most of the Shimeji's can be updated by simply replacing the newer version of <code>Shimeji-ee.jar</code>, <code>lib</code> and <code>conf</code> folder. Do not replace the <code>img</code> folder.

⚠ **EXCEPTION:** **The Coal Tar Shimeji** has different configurations, it needs to retain the code from <code>actions.xml</code> and <code>behaviors.xml</code> that dictates the number of images it actually has. (120 images)
